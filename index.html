Tambah Transaksi
Isi bagian di bawah HANYA jika saham sudah terjual. Kosongkan semua jika masih dipegang (Open) — harga saat ini akan terisi otomatis secara realtime, kolom ini hanya untuk override manual bila diperlukan.

1 lot = 100 lembar saham. Fee beli/jual dalam persen dari nilai transaksi (mis. fee jual sering ~0.25% karena sudah termasuk PPh final 0.1%). "Total Beli"/"Total Jual" sudah termasuk fee. "Harga Saat Ini" untuk posisi Open diambil otomatis tiap 60 detik dari Yahoo Finance (kode saham + .JK, BEI) — fitur ini butuh koneksi internet; jika gagal, isi manual lewat tombol Edit. Data transaksi tersimpan otomatis secara OFFLINE di browser perangkat ini (localStorage) — tetap tersimpan walau file dibuka tanpa internet. Gunakan tombol Export/Import Data untuk backup atau memindahkan data ke komputer/browser lain.
